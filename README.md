### 📌 What is this?

**VortexOS** is my custom-built, highly optimized Linux distribution built on top of Arch Linux. It is designed to deliver blistering speed, fluid Wayland animations via **Hyprland**, and uncompromised security. Proudly developed in Saudi Arabia 🇸🇦, it is built to monitor, manage, and secure my own environment.

### 💻 The S_12 Security Engine Showcase

> *I built VortexOS with the custom S_12 Security Engine integrated at its core. It is designed to be clean, ruthless, and straight to the point. No bloatware, no clutter—just raw execution, deep system hardening, and maximum protection.*

---

### ⚙️ How it works

* **Hyprland Optimization:** Pre-configured for hyper-smooth window management, utilizing minimal system resources for maximum visual output.
* **S_12 System Hardening:** Deep system audits, automated security scripts, and secure kernel parameters ready out of the box.
* **Terminal UI Focused:** Designed specifically for developers and power users. If you live in the terminal, this OS feels like home.
